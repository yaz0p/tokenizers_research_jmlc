# TLDR
В этом репозитории находится код по исследованию, связанному с ускорением обучения модели под конкретные домены.

# С какой проблемой я боролся?
Обычно, языковые модели используют под конкретные домены, и не на всех доменах модели себя показывают должным образом.
Также есть проблема, что для различных доменов токены в себе инкапсулируют разное количество информации.

# Что я сделал?
Столкнувшись с проблемами этими проблемами я придумал, как можно улучшить доменные знания модели + увеличить потенциальный контекст модели, путем увеличения емкости модели.
В ходе моих эксперементов выяснилось, что можно увеличить контекст модели на ~35%, ускорить prefill этап на ~35%, ускорить инференс на доменных задачах.
Также эмпирически был подобран способ инициализации токенов, благодаря которому обучение шло быстрее, чем при инициализации из нормального распределения.

# Что можно увидеть?
В репозитории можно увидеть: Jupiter Notebooks к эксперементами в вольном формате; модуль, в котором хранится логика для расширения токенизатора на определенный домен; результаты моей работы.
